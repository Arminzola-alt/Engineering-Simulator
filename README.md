# Engineering Simulator

An interdisciplinary engineering project built around a smart water-treatment plant. **Chemical**, **Mechanical** and **Electronics** engineering each get their own live, interactive simulator.

**Assignment:** design a software project that reflects interdisciplinary engineering work (at least three engineering departments).

## Simulators
- **Chemical Engineering:** water-treatment tank with pH dosing, filtration, safety interlocks and auto/manual control
- **Mechanical Engineering:** pump and piping system with a pump curve vs system curve, valve, filter clogging and efficiency
- **Electronics Engineering:** pH sensor signal chain (probe, amplifier, ADC) with an oscilloscope view, plus PWM motor drive

## Run locally
Open `index.html` in any browser.

## Deploy on GitHub Pages
1. Push this repo to GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Your site appears at `https://<your-username>.github.io/<repo-name>/`.

## Customise
Edit the `CONFIG` block near the top of the script in `index.html` to set your name, class and college.
